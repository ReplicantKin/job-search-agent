# Privacy

Job Search Agent is local-first. It does not operate a hosted account or central database in its default distribution.

Users decide what personal information, job history, browser access, and credentials to provide. Credentials are stored separately from the job database through a local credential-store interface and are excluded from JSON and Markdown exports.

The plugin does not silently read browser passwords, scan unrelated local files, or upload personal data in the background. Browser actions require explicit user authorization and pause when authentication challenges, CAPTCHA, unknown questions, or sensitive commitments appear.

Site-specific terms and privacy policies remain applicable when the plugin visits or interacts with a recruitment website.
